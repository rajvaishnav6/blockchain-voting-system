# 🗳️ ChainVote – Blockchain Voting System

A secure, transparent, and decentralized blockchain-based voting application built using Ethereum, Solidity, React, Node.js, Express, SQLite, and MetaMask.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/rajvaishnav6/blockchain-voting-system.git
```

Install Dependencies

```bash
cd frontend
npm install

cd ../backend
npm install

cd ../blockchain
npm install
```

---

# 🚀 Run Project

Frontend

```bash
npm run dev
```

Backend

```bash
npm start
```

Smart Contract

```bash
npx hardhat compile
npx hardhat run scripts/deploy.js --network sepolia
```
